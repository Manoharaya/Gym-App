# FitCore Asynchronous Background Workers

## Purpose

Event-driven worker processes for long-running and scheduled jobs:

- Nightly recurring billing cycles, failed payment retries, and invoice generation.
- Batch syncing of wearable telemetry data from third-party APIs (Fitbit, Garmin, Whoop, Oura).
- Scheduled push notification broadcasts and booking reminder dispatches.
- Daily Xero ledger reconciliation and financial report aggregation.

_Implementation scheduled for subsequent project milestones._
