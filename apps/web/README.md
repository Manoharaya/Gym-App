# FitCore Web Member & Public Portal

## Purpose

Next.js-based web application providing:

- Public club landing pages and membership sign-up funnels.
- Member portal for bookings, training logs, account management, and payment receipts.
- Responsive web experience complementing the native mobile apps.

## Architecture

- Shares domain types from `@fitcore/types`.
- Shares validation schemas from `@fitcore/validation`.
- Shares API client from `@fitcore/api-client`.
- Shares design tokens from `@fitcore/ui`.

_Implementation scheduled for subsequent project milestones._
