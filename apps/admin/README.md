# FitCore Superadmin & Enterprise Console

## Purpose

Web-based superadmin and organisation management dashboard:

- Multi-organisation onboarding and billing management.
- System-wide audit logging and tenant configuration.
- Global AI gateway configuration, credit balance controls, and usage analytics.
- Global door-access hardware and integration monitoring (Xero, Stripe).

## Security

- Restricted exclusively to `SUPERADMIN` and `ORGANISATION_OWNER` with elevated hardware 2FA.
- Full tamper-evident audit logging for all mutations.
