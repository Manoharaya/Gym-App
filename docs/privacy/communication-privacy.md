# Communication Privacy & Day 28 Integration

## 1. Unified Preferences
FitCore uses Day 28's `CommunicationPreference` architecture to govern messaging channels (Email, SMS, WhatsApp, Push).

## 2. Hard Security Ceiling
Privacy preferences cannot disable mandatory security or transaction notices:
- Password reset links
- MFA verification challenges
- Account lockout warnings
- Membership tax invoices and payment failure alerts
- Urgent facility emergency notices

All optional marketing and non-essential engagement nudges can be toggled by the member at any time.
