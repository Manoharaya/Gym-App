# Communication Billing

Integration with Day 28 Communication & Notification Engine.

## Metered Channels
- `SMS_MESSAGE`: Authoritative message records from Twilio/SendGrid.
- `WHATSAPP_MESSAGE`: Verified delivered WhatsApp conversations.
- `EMAIL_MESSAGE`: Tracked transactional and marketing emails beyond free allowances.

Only channels enabled on the gym's plan tier are counted towards billable overage meters.
