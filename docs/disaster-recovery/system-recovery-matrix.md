# System Recovery Matrix

The following matrix documents the criticality, source of truth, backup method, replication, target RPO, target RTO, restore procedures, dependencies, and validation methods for all major FitCore components.

| Component | Criticality | Source of Truth | Backup Method | Backup Frequency | Replication | Retention | RPO Target | RTO Target | Restore Method | Dependencies | Validation Method | Owner |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **PostgreSQL** | Tier 0 (Critical) | Primary RDS / PG Instance | Encrypted `pg_dump` + WAL archive | Continuous WAL + 6h Snapshot | Multi-AZ + Cold S3 cross-region | 30 Days (Immutable) | `< 15 min` | `< 60 min` | Point-in-time recovery (PITR) to standby host | KMS, VPC, S3 | `DataIntegrityValidatorService`, foreign keys | Data Engineering |
| **Auth & Sessions** | Tier 0 (Critical) | PostgreSQL (`users`, `sessions`) | Database snapshot | Continuous | Multi-AZ | 30 Days | `< 15 min` | `< 30 min` | Database restore + session invalidation on high risk | PostgreSQL, Redis | Password hash integrity, MFA TOTP secrets check | Security Team |
| **Membership** | Tier 0 (Critical) | PostgreSQL (`member_memberships`) | Database snapshot | Continuous | Multi-AZ | 30 Days | `< 15 min` | `< 30 min` | Database restore | PostgreSQL | Active accessScope validation, plan entitlement checks | Product Eng |
| **Access Control (Turnstiles)** | Tier 0 (Critical) | PostgreSQL (`access_credentials`) | Local reader cache + DB snapshot | Continuous | Reader flash storage | 30 Days | `< 15 min` | `< 15 min` | Local cached policy fallback + DB restore | Network, PostgreSQL | Badge swipe simulation, fail-secure verification | IoT/Hardware Team |
| **Payments & Invoicing** | Tier 0 (Critical) | PostgreSQL (`payment_transactions`) | Database snapshot | Continuous | Multi-AZ | 7 Years (Financial compliance) | `< 15 min` | `< 60 min` | DB restore + Gateway Reconciliation (`UNKNOWN` &rarr; verified) | Stripe, GoCardless, KMS | Idempotency replay check, reconciliation scan | FinOps / Core API |
| **Bookings & Sessions** | Tier 0 (Critical) | PostgreSQL (`bookings`, `class_sessions`) | Database snapshot | Continuous | Multi-AZ | 90 Days | `< 15 min` | `< 30 min` | DB restore | PostgreSQL | Capacity invariant check (zero overbooking) | Core API |
| **Queues (BullMQ)** | Tier 1 (High) | Redis persistent storage (AOF/RDB) | Redis snapshot (RDB) | Every 1h | In-memory replica | 7 Days | `< 60 min` | `< 30 min` | Redis snapshot restore + DLQ recovery | Redis, Workers | `QueueTelemetryService`, zero DLQ saturation | Platform Eng |
| **Background Workers** | Tier 1 (High) | Stateless container image | Git / Container Registry | Per deployment | ECR / Docker Hub | 10 releases | `0 min` (Stateless) | `< 15 min` | Kubernetes / ECS task relaunch | Redis, PostgreSQL | Worker heartbeat, job consumer ping | Platform Eng |
| **AI Gateway** | Tier 1 (High) | External LLM Provider + DB config | DB snapshot | Continuous | Multi-provider fallback | 30 Days | `< 15 min` | `< 10 min` | Fallback to static rule-based templates | Anthropic, OpenAI | Token metrics probe, prompt safety checks | AI Engineering |
| **SaaS Billing** | Tier 1 (High) | PostgreSQL (`saas_subscriptions`) | Database snapshot | Continuous | Multi-AZ | 7 Years | `< 15 min` | `< 60 min` | DB restore + period finalization check | PostgreSQL, Stripe | Subscription entitlement & quota validation | SaaS Billing Team |
| **Object Storage (Media & Docs)** | Tier 2 (Important) | AWS S3 Bucket | S3 Cross-Region Replication + Versioning | Continuous | Secondary Region (Cold) | 365 Days | `< 60 min` | `< 120 min` | S3 bucket version restore / replication sync | S3, IAM | Checksum validation, signed URL probe | Platform Eng |
| **Accounting Integration** | Tier 2 (Important) | FitCore DB (Authoritative) + Xero/QBO | DB snapshot | Continuous | Outbox queue | 30 Days | `< 15 min` | `< 120 min` | Re-queue pending outbox sync items | Xero, QuickBooks | Idempotent ledger sync validation | Integrations Team |
| **Wearables Integration** | Tier 2 (Important) | External Provider API + DB snapshot | DB snapshot | Continuous | N/A | 30 Days | `< 24 h` | `< 120 min` | Retrospective interval sync | Fitbit, Apple Health | Webhook ingest verification | Integrations Team |
| **Temporary Caches** | Tier 3 (Recoverable) | Redis memory | Reconstructable | Ephemeral | In-memory | N/A | N/A (Disposable) | `< 5 min` | Lazy cache warm-up on request | Redis | Latency baseline check | Platform Eng |
