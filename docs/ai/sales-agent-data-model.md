# FitCore AI Sales Agent Data Model

## Overview
The AI Sales Agent introduces dedicated multi-tenant Prisma models while linking directly with core Gym OS entities (`Organisation`, `Outlet`, `Lead`, `StaffProfile`, `MembershipPlan`).

## Core Models

### 1. `SalesAgentProfile`
Configures the behavioral persona, tone, style, and enabled features for an organisation or specific outlet.
- `salesStyle`: `CONSULTATIVE` | `ENERGETIC` | `PREMIUM` | `DIRECT` | `SUPPORTIVE`
- `tone`: `FRIENDLY` | `PROFESSIONAL` | `CASUAL` | `ENTHUSIASTIC`
- `qualificationEnabled`: Boolean
- `recommendationEnabled`: Boolean
- `humanHandoffEnabled`: Boolean
- `targetAudience`: Target demographic notes
- `businessDescription`: Modality description (CrossFit, Pilates, 24/7 Gym, etc.)

### 2. `SalesConversation`
Represents an ongoing prospect sales dialogue across channels (`WEB`, `WHATSAPP`, `SMS`, `WALK_IN`).
- `leadId`: Relates to Day 33's `Lead`.
- `status`: `ACTIVE` | `QUALIFYING` | `RECOMMENDING` | `CONVERTED` | `LOST` | `HANDED_OFF` | `COMPLETED`
- `discoveredGoals`: String array of fitness objectives.
- `discoveredSchedule`: JSON object containing frequency, preferred time of day, preferred days.
- `discoveredExperience`: `BEGINNER` | `INTERMEDIATE` | `ADVANCED`
- `discoveredReadiness`: `CURIOUS` | `INTERESTED` | `READY_FOR_TRIAL` | `READY_TO_JOIN`
- `discoveredBudget`: Price sensitivity tier
- `currentIntent`: Detected sales intent of the latest message

### 3. `SalesConversationMessage`
Maintains conversational transcript with role (`CUSTOMER`, `AI`, `STAFF`, `SYSTEM`), token counts, language, and latency.

### 4. `SalesRecommendation`
Captures grounded recommendations generated by the AI:
- `recommendationType`: `MEMBERSHIP_PLAN` | `CLASS_PACK` | `PERSONAL_TRAINING` | `TRIAL_PASS` | `FACILITY_TOUR`
- `recommendedPlanId`: Foreign key to `MembershipPlan`.
- `reason`: Rationale tied to prospect goals.
- `supportingFactors`: Array of supporting factual reasons.
- `limitations`: Honest plan exclusions (e.g., "Peak hours restricted", "No PT included").
- `nextBestAction`: Recommended next step.

### 5. `SalesNextAction`
Actionable next step tracked through execution:
- `actionType`: `BOOK_TRIAL` | `BOOK_TOUR` | `BOOK_CLASS` | `REQUEST_CALLBACK` | `CONNECT_WITH_STAFF` | `VIEW_MEMBERSHIP_OPTIONS`
- `status`: `RECOMMENDED` | `EXECUTED` | `DECLINED` | `EXPIRED`
- `payload`: Execution parameters (e.g., preferred trial date, tour time).

### 6. `SalesHandoff`
Escalation record to staff:
- `reason`: `CUSTOMER_REQUESTED_HUMAN` | `HIGH_VALUE_PROSPECT` | `PRICING_EXCEPTION` | `MEDICAL_SAFETY_CONCERN` | `COMPLEX_INQUIRY` | `NEGATIVE_SENTIMENT`
- `priority`: `LOW` | `MEDIUM` | `HIGH` | `URGENT`
- `status`: `PENDING` | `CLAIMED` | `RESOLVED` | `EXPIRED`
- `assignedStaffId`: Relates to `StaffProfile`.
